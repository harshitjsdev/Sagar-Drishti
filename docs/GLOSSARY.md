# Glossary

  -----------------------------------------------------------------------
  Term                                Meaning
  ----------------------------------- -----------------------------------
  AI Tutor / Ocean Tutor              Backend-mediated assistant intended
                                      to explain ocean-science concepts

  Argo                                Ocean profiling-float observation
                                      programme

  Copernicus Marine                   Service providing marine datasets,
                                      including model products depending
                                      on dataset

  Data provenance                     Information describing data origin
                                      and processing

  Depth                               Vertical position below the ocean
                                      surface, often in metres

  ERDDAP                              Framework/service for accessing
                                      scientific datasets

  Fallback/demo data                  Substitute content used when a live
                                      service is unavailable; not live
                                      observation

  Flask                               Python web framework used by the
                                      documented backend

  Gemini                              AI service integrated with the
                                      tutor when configured

  INCOIS                              Indian National Centre for Ocean
                                      Information Services

  Interpolation                       Estimating values between available
                                      data points

  Leaflet                             JavaScript library for interactive
                                      maps

  Model output                        Value produced by a numerical model
                                      rather than directly measured

  NetCDF                              File format commonly used for
                                      multidimensional scientific data

  Observation                         Measurement collected by an
                                      observing system

  Profile                             Measurements associated with a
                                      vertical sequence, such as depth

  QC                                  Quality control checks or flags

  REST API                            HTTP interface used by software
                                      components to exchange information

  Salinity                            Measure of dissolved salts in water

  Three.js                            JavaScript library for
                                      browser-based 3D graphics

  `thetao`                            Ocean temperature variable in the
                                      supplied Copernicus subset example

  WSGI                                Interface between Python web
                                      applications and web servers
  -----------------------------------------------------------------------
